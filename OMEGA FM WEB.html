AUDIO SETUP — select devices once, then start

Asked once — lets the browser reveal your inputs (line-in, VB-Cable, VoiceMeeter…) and outputs by name.
The DSP chain runs on every 128-sample browser callback (uniform CPU load — no periodic spikes). The buffer above only adds output buffering: larger = more glitch protection, smaller = lower monitoring latency.
⚠ Feedback: microphone in + speakers out will howl, and monitoring your own mic always sounds like a short echo (processing latency). Use headphones, a line input, or a virtual cable for the program feed.
